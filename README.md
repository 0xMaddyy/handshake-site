# 0xMaddyy

One-page personal site for the Handshake mission
[Learn the Terminal Developers Use Every Day](https://joinhandshake.com/learn/learn-the-terminal-developers-use-every-day-d8839165/).

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## The line you change

Edit `note` in `app/content.ts`, then commit and push. That sentence is the lime “Latest note” on the page.
